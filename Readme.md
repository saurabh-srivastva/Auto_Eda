# 🧠 Auto EDA

A fully Python-based **Automated Exploratory Data Analysis (EDA)** web app built with **Streamlit**.  
This tool allows users to upload CSV files, instantly explore data insights, visualize correlations, and generate summary reports — all with one click.

---

## 🚀 Features

- 📂 Upload CSV files easily
- 📊 Automatic data cleaning and type conversion
- 🔍 View dataset summary (shape, missing values, datatypes)
- 📈 Generate charts and correlations instantly
- 🌙 Toggle between Light/Dark themes
- 🧮 Download processed data and reports

---

## 🛠️ Tech Stack

- **Python 3.10+**
- **Pandas**
- **Numpy**
- **Matplotlib / Seaborn / Plotly**
- **Streamlit**
